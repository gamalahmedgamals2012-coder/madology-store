# QUICK START - 2 MINUTES ⚡

## For Windows Users

```
1. Extract the folder
2. Double-click "setup.bat"
3. Wait for installation
4. Run: npm start
5. Open: http://localhost:3000
```

## For Mac/Linux Users

```
1. Extract the folder
2. Open Terminal in this folder
3. Run: bash setup.sh
4. Run: npm start
5. Open: http://localhost:3000
```

## Manual Setup (Any OS)

```
1. Open Terminal/Command Prompt
2. Navigate to this folder
3. Run: npm install
4. Run: npm start
5. Open: http://localhost:3000
```

## Test the App

### Register

- Click user icon (right in navbar)
- Fill form with test data
- Click "Register"

### Shop

- Go to "Shop"
- Click "Add To Cart"
- Click cart icon to view

### Order

- Click cart icon
- Click "Order Now"

### Admin (View Orders)

- Go to: http://localhost:3000/admin.html

## Options

### Option A: Simple Server (NO DATABASE) ✅ BEST

```bash
npm start
```

Uses JSON file storage. No MongoDB needed.

### Option B: Full Server (WITH MONGODB)

```bash
npm run dev
```

Requires MongoDB running on localhost:27017
